# Contributing to the AI Tools Directory

Thank you for helping improve this community-maintained directory. Contributions from students, developers, researchers, creators, and organizations are welcome.

By contributing, you help people discover useful AI tools and keep listings accurate.

## Ways to Contribute

You can contribute by:

- Adding a genuine AI tool that is not already listed.
- Updating a tool's official website or category.
- Reporting a broken, redirected, or incorrect link.
- Correcting inaccurate descriptions or pricing information.
- Improving category navigation, accessibility, or documentation.
- Suggesting new categories or directory improvements.

## Before You Submit

Please check that:

1. The tool is not already listed under another name or category.
2. The link points to the tool's official website, official project page, or official source-code repository.
3. The tool has a clear AI-related feature or purpose.
4. The category accurately describes the tool.
5. Any claims about free access, open-source status, or commercial use are supported by current official information.
6. You have the right to contribute any text or other material you submit.

Free plans, usage limits, licenses, and commercial-use terms can change. When unsure, omit the claim rather than guessing.

## Add a Tool

Add the entry under the most relevant category in `README.md` or the appropriate data file, keeping the existing alphabetical or category ordering where practical.

Use this format:

```markdown
- [Tool Name](https://official-website.example)
```

If the repository uses a structured data file for listings, follow its existing format instead.

### Optional Description

Only add a short description if the surrounding category already uses descriptions:

```markdown
- [Tool Name](https://official-website.example) — Brief, factual description of its AI feature.
```

Do not add referral links, URL shorteners, affiliate tracking links, or promotional slogans.

## Report a Broken Link or Incorrect Listing

When opening an issue, include:

- The tool name.
- The current listing or URL.
- What appears to be wrong.
- The corrected official URL or a reliable source, if available.

Please do not include passwords, API keys, private user data, or other sensitive information in an issue.

## Submit a Pull Request

1. Fork the repository.
2. Create a branch for your change.
3. Make the smallest focused change that solves the issue.
4. Check for duplicate entries and verify links.
5. Preview the Markdown to confirm headings and links render correctly.
6. Commit your changes with a clear message, such as `Add Example AI Tool`.
7. Open a pull request and explain what changed and why.

For small edits, a concise explanation is enough. For larger changes, describe the categories or files affected and any checks you performed.

## Pull Request Checklist

Before submitting, confirm:

- [ ] The tool is not already listed.
- [ ] The link is official and works.
- [ ] The tool has a relevant AI-related use.
- [ ] The category is appropriate.
- [ ] Pricing, open-source, and license claims are not misleading.
- [ ] No referral, tracking, or URL-shortener links were added.
- [ ] Markdown formatting and category jump links still work.
- [ ] I have the right to contribute the submitted material.

## Inclusion Guidelines

Listings are for discovery and are not endorsements. A tool may be included whether it is free, freemium, paid, or open source, as long as its status is represented accurately and the category is appropriate.

Do not:

- Submit fake tools, duplicate entries, spam, or unrelated products.
- Claim a tool is open source unless its source code and license support that claim.
- Describe a tool as completely free if it has meaningful paid restrictions.
- Copy large amounts of third-party website text without permission.
- Submit malware, phishing services, or tools intended to facilitate abuse.
- Add personal data or confidential information.

## Licensing and Contributions

Only submit content you created or are authorized to share. By submitting a contribution, you confirm that you have the right to submit it under the repository's applicable license.

The repository's `LICENSE` file determines the terms for material it covers. If different licenses apply to code and directory content, follow the license notice for the relevant files. Do not assume that a repository license grants rights to third-party tool names, logos, trademarks, or websites.

If you are unsure whether material can be contributed, open an issue to ask before submitting it.

## Community Standards

Be respectful, constructive, and open to review. Explain disagreements with evidence, focus feedback on the contribution rather than the contributor, and accept that maintainers may request changes or decline entries that do not meet these guidelines.

## Questions

If you are unsure where a tool belongs or how to make a change, open an issue with your question.

Thank you for helping keep the AI tools directory useful, accurate, and accessible.
